# Figo コーポレートサイト

株式会社Figoのコーポレートサイト（リニューアル版）。本番: https://site-one-delta-46.vercel.app

## 技術スタック

- Next.js 14 (App Router)
- React 18 / TypeScript
- Tailwind CSS v3
- ESLint / Prettier

## セットアップ

```bash
npm install
npm run dev
```

`http://localhost:3000` を開く。

## 主要コマンド

| コマンド | 用途 |
| --- | --- |
| `npm run dev` | 開発サーバー起動 |
| `npm run build` | 本番ビルド |
| `npm run start` | ビルド結果の起動 |
| `npm run lint` | ESLint |
| `npm run typecheck` | TypeScript 型チェック |
| `npm run format` | Prettier 整形 |
